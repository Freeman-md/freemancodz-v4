# Public home
Mode: Experience, with a focused audit invitation. Scope: the single-page public portfolio, its navigation and legacy entry URLs. CMS records, assistant workflows and admin remain authoritative.

## Direction contract
THESIS: Working objects. Visitors see the customer-facing interface and the operational follow-through as one piece of engineering. This replaces the disconnected editorial pages.
OWN-WORLD: Frost-white display space, navy, mint, softly lit dimensional project imagery; Manrope display and Inter reading text. Glass belongs to floating navigation only.
STORY: Understand the offering → inspect real payment work → try the assistant and see workflow thinking → meet Freeman → bring one journey for review.
FIRST VIEWPORT: Centered two-line display title above an asymmetric arrangement of existing project imagery and a working assistant entry. One primary work anchor. No invented evidence.
FORM: Persona-inspired product display with real project interfaces, asymmetric composition and dimensional surfaces. CodeFast informs the progression from work to explanation, personality and invitation.
MOTION: Project planes settle with scroll; native anchors connect scenes; 200ms ease-out disclosures and press feedback. No hidden reading content. Reduced motion disables all movement.

## Interaction decisions
- Navigation uses anchors; actions open the existing assistant (`rule/navigation-vs-action`).
- Project, career and audit depth expands inline (`rule/inline-before-modal`).
- Audit intake remains reviewable before its existing confirmation step (`rule/irreversible-action-safeguard`). No real request or booking is submitted in verification.
- All content stays readable before animation; media errors retain context without inventing images (`rule/cover-reachable-states`).
- Shared-element routing is unnecessary for one document; installed Next.js 16.2.12 labels its integration experimental. Existing Framer Motion is retained for bounded depth movement.

Regular: [quiet navigation] / [display + concise offer] / [dimensional real work] / [image + case study] / [dark assistant + workflow] / [person + inline depth] / [mint audit invitation]
Compact: same story, one focal artifact at a time, stacked content, visible section navigation and compact corner assistant.
